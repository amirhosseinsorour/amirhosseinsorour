# Amirhossein Sorour

**Data Analytics · Statistical Modelling · Quantitative Finance**

Toronto, Canada · [LinkedIn](https://www.linkedin.com/in/amirhossein-sorour/) · [Email](mailto:amirhosseinsorour@gmail.com)

I hold an **MSc in Applied Modelling & Quantitative Methods** from **Trent University** and a **BSc in Computer Engineering** from **Amirkhabir University of Technology**.

My interests include data and product analytics, financial and risk analysis, and optimization. I use statistical models and computational tools to explore data, compare alternatives and communicate findings.

## Selected projects

| Project | Focus |
| --- | --- |
| [Mass Spectral Probability Calibration](https://github.com/amirhosseinsorour/Mass-Spectral-Probability-Calibration) | **MSc project.** Compared logistic and isotonic probability mappings for mass spectral comparisons, using grouped evaluation on highly imbalanced data. |
| [Markowitz Portfolio Optimization](https://github.com/amirhosseinsorour/Markowitz-Portfolio-Optimization) | Compared equal-weight, minimum-variance and maximum-Sharpe allocations using Excel Solver, covariance modelling and portfolio simulation. |

| [Distracted Driver Detection](https://github.com/amirhosseinsorour/Detection-of-Distracted-Driver-using-CNN) | VGG16-based image classification with image preprocessing, MATLAB data augmentation and model evaluation. |
